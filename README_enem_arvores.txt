
Protótipo mínimo "Enem com Árvores"
Arquivos gerados:
- /mnt/data/enem_arvores_prototipo.py : script Python executável (Tkinter)
- /mnt/data/README_enem_arvores.txt : instruções rápidas
Como usar:
1. Baixe o arquivo e execute localmente: python enem_arvores_prototipo.py
2. No menu, clique em 'Novo Jogo' e informe seu nome.
3. Vá em 'Mapa dos Atos' e clique 'Iniciar' em qualquer ato para iniciar a missão protótipo.
4. No mini-game 'Ritual de Plantio' memorize e repita a sequência de cores.
Salvamento: o jogo salva em 'enem_arvores_save.json' no mesmo diretório.
